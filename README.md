Overview
--------

* **AI-Powered Design**  Buildable is a parametric 3D
modeler with an integrated AI assistant that lets you describe what you want
to build in natural language.
Parametric modeling allows you to easily modify your design by going back into
your model history to change its parameters.

* **Create 3D from 2D and back** Buildable lets you sketch geometry-constrained
 2D shapes and use them as a base to build other objects.
 It contains many components to adjust dimensions or extract design details from
 3D models to create high quality production-ready drawings.

* **Designed for your needs** Buildable is designed to fit a wide range of uses
including product design, mechanical engineering and architecture,
whether you are a hobbyist, programmer, experienced CAD user, student or teacher.

* **Cross platform** Buildable runs on Windows, macOS and Linux operating systems.

* **Underlying technology**
    * **OpenCASCADE** A powerful geometry kernel, the most important component of Buildable
    * **Coin3D library** Open Inventor-compliant 3D scene representation model
    * **Python** Buildable offers a broad Python API
    * **Qt** Graphical user interface built with Qt

Reporting Issues
---------

To report an issue please:

- Search the existing [issues](https://github.com/buildable-to/Buildable/issues) for potential duplicates;
- Use the most updated stable or [development versions](https://github.com/buildable-to/Buildable/releases/) of Buildable;
- Post version info from `Help > About Buildable > Copy to clipboard`;
- Post a Step-By-Step explanation on how to recreate the issue;
- Upload an example file (FCStd as ZIP file) to demonstrate the problem;

For more details see:

- [Bug Tracker](https://github.com/buildable-to/Buildable/issues)
- [Reporting Issues](https://github.com/buildable-to/Buildable/issues/new/choose)
