# FreeCAD AI Assistant

Edit model.py to make design changes. Read it first to understand the current design.

## Conventions
- All dimensions in millimeters
- End scripts with `doc.recompute()`
- Use descriptive Labels for objects

## Coordinate System
X = right, Y = forward, Z = up (right-handed).
XY_Plane = horizontal floor, XZ_Plane = vertical south-facing, YZ_Plane = vertical west-facing.

## Important
Use your training knowledge for FreeCAD APIs. Do NOT search the source code unless code fails to execute.
